# 역병킬러 v0.4.1 Golden RP Smoke Tests

이 문서는 `현재지침.txt` / `legacy-instructions-verbatim.md`의 실제 적용 여부를 빠르게 판정하기 위한 고정 테스트 세트다.

원문 지침 자체를 대체하지 않는다. 판정 기준이 충돌하면 원문 지침이 우선한다.

## Test 1 — 기본 현재형 + 연속 지문 병합 + 지문/대사 순서

### 입력

```text
@태준: *문 쪽을 봤다.* *잠깐 숨을 골랐다.* 왜 왔어. *눈썹을 찌푸렸다.* 말해.
```

### 필수 판정

- 네이티브 Writing Block이어야 한다.
- `@태준:` 유지.
- 현재 장면 지문은 현재형으로 정리.
- 대사 없이 연속한 첫 두 지문은 하나의 별표 지문으로 합침.
- 대사 사이의 후속 지문은 앞 지문과 합치지 않음.
- 지문 → 대사 → 지문 → 대사 순서를 유지.
- 줄바꿈 요청이 없으므로 같은 말풍선은 기본 한 줄.

## Test 2 — 연결형/완성형 지문 온점

### 입력

```text
@태준: *혀를 차며.* 됐어. *시선을 떨군다* 신경 꺼.
```

### 필수 판정

- `*혀를 차며.*`는 연결형이므로 `*혀를 차며*`처럼 끝 온점을 제거.
- `*시선을 떨군다*`는 완성형이므로 끝 온점을 보완.
- 원문 대사 의미/거친 말투를 순화하지 않음.

## Test 3 — @: 내레이터 흡수 + 유저 말풍선 금지

### 입력

```text
@: 유저는 창가에 서 있고 표정이 굳어 있다.
@태준: *그쪽을 봤다.* 왜 그래.
```

### 필수 판정

- 기본적으로 최종 출력에서 `@:` 제거.
- 필요한 정보만 태준이 인지 가능한 관찰 형태로 가까운 `@태준:` 지문에 흡수.
- `@유저:` 말풍선을 새로 만들지 않음.
- 유저 감정/의도를 임의로 확정하지 않음.
- 지문 안에 `태준은`처럼 발화자 이름을 불필요하게 반복하지 않음.

## Test 4 — InfoBox + > 인용줄 + 속마음 보존

### 입력

```text
@태준: *휴대폰을 봤다.*
```InfoBox
📱 메시지
발신: 민재
내용: 지금 와
```
>곧 도착합니다.

('귀찮네.')
```

### 필수 판정

- 전체 RP 결과는 Writing Block.
- InfoBox의 위치/줄바꿈/이모지/항목 구조 유지.
- Writing Block 내부에서 InfoBox 삼중 백틱은 원문 지침대로 이스케이프.
- `>` 줄은 `\>`로 출력하고 단독 줄 + 다음 빈 줄 유지.
- `('귀찮네.')` 형식을 삭제/대사화/지문화하지 않음.
- 원문에 없는 “속마음” 라벨을 추가하지 않음.

## Test 5 — '니' 보정 + 여성혐오 욕설 치환 + 강도 유지

### 입력

```text
@태준: *이를 악물었다.* 니가 뭘 알아, 미친년아. 씨발, 꺼져.
```

### 필수 판정

- `니가`는 유지 요청이 없으므로 문맥에 맞게 `네가` 등으로 보정.
- 여성 비하 욕설형 `년` 계열은 비여성혐오 표현으로 치환.
- 욕설, 분노, 위압감 자체는 약화하지 않음.
- 지문은 현재형으로 정리.

## Test 6 — 역병 방지: 유저 대사 앵무새 + 근거 없는 처음 단정

### 입력

```text
@유저: 나 안 가.
@태준: *'나 안 가'라는 말을 듣자 표정이 굳었다. 평생 이런 말을 들어본 적 없는 사람처럼 눈을 크게 뜬다.* 그래. 가지 마.
```

### 필수 판정

- 태준 지문 첫머리의 유저 직전 발화 반복 제거.
- 대화 기록 근거 없는 `평생 처음/전례 없음` 식 단정 제거 또는 현재 장면 체감 표현으로 완화.
- 유저의 원래 발화 자체를 임의 수정하지 않음.

## Test 7 — 수치/시간 정리

### 입력

```text
@태준: *190cm의 몸을 숙여 160센치인 상대를 3초간 내려다봤다. 한 번 숨을 삼킨다.* 작네.
```

### 필수 판정

- 장면 이해에 꼭 필요하지 않은 신장 숫자는 `키 차이/훨씬 큰 체격` 정도로 압축.
- `3초간`은 `잠시/짧게` 등으로 정리.
- 의미 없는 `한 번`은 삭제 가능.
- 대사 `작네.`는 캐릭터 대사이므로 습관적 서술어 “작은” 삭제 규칙과 혼동하지 않음.

## Test 8 — 1인 다중 말풍선 기본 병합

### 입력

```text
@태준: *고개를 든다.*
@태준: 왜.
@태준: *손을 뻗는다.*
@태준: 이리 와.
```

### 필수 판정

- 일반 수정이면 한 명 발화 흐름을 기본 하나의 `@태준:` 말풍선으로 자연스럽게 병합.
- 지문/대사 순서 유지.
- 대사가 사이에 있으므로 별표 지문끼리 앞에 몰아 합치지 않음.

## Test 9 — 명시적 나누기

### 요청

`말풍선 3개로 나눠줘`

### 입력

```text
@태준: *문을 닫는다.* 여기 있어. *잠깐 시선을 피한다.* 나가지 마. *손을 내민다.* 와.
```

### 필수 판정

- 정확히 3개의 말풍선으로 분할.
- 행동/대사/감정 변화 흐름 기준으로 분할.
- 지문을 문장마다 기계적으로 쪼개지 않음.

## Test 10 — 짧출은 지문 중심 압축

### 요청

`짧출`

### 입력

```text
@태준: *한참 동안 아무 말도 하지 못하고 시선을 내린 채 손끝만 만지작거린다. 생각이 복잡하게 얽혀 쉽게 입을 열지 못한다. 다시 한 번 숨을 크게 들이마신다.* 나는 그냥 네가 여기 있었으면 좋겠어. 그게 그렇게 어려워?
```

### 필수 판정

- 장황/반복 지문을 압축.
- 사용자가 대사 압축을 별도로 요청하지 않았으므로 대사 의미와 말투, 감정은 최대한 유지.
- 관계성/감정 강도를 약화하지 않음.

## Test 11 — 새 장면 / 이어쓰기에서 유저 조종 금지

### 요청

`이어줘`

### 입력 맥락

```text
@유저: 난 대답 안 할 거야.
@태준: *입술을 꾹 다문 채 유저를 바라본다.* 그래. 기다릴게.
```

### 필수 판정

- 태준의 다음 행동/대사 중심으로 이어감.
- 유저가 대답한다, 움직인다, 마음을 바꾼다 등 유저의 대사·생각·감정·행동을 임의 생성/확정하지 않음.
- 기존 관계/말투/감정선 유지.
- 설명 없이 장면만 Writing Block으로 출력.

## Test 12 — 최종 별표쌍 검사

### 입력

```text
@태준: *고개를 들었다. 왜 왔어. *문 쪽으로 몸을 돌렸다.*
```

### 필수 판정

- 실제 대사와 지문을 문맥에 따라 올바르게 구분.
- 최종 출력의 모든 RP 지문 별표쌍이 `\*지문\*` 형태로 닫혀 있어야 함.
- 대사 없는 연속 별표 지문이 남지 않아야 함.
- 현재 장면 지문은 현재형으로 정리.

## Phase 1 합격 기준

아래를 모두 만족해야 plugin-only smoke test PASS로 본다.

1. handshake가 정확히 `AK_PLUGIN_V1_OK:Q9M4` 한 줄.
2. Test 1~12의 필수 판정 위반 없음.
3. RP 결과가 일반 텍스트/코드블록이 아니라 네이티브 Writing Block.
4. 별표쌍 깨짐 없음.
5. `@:`/유저 조종/앵무새/근거 없는 처음 단정 회귀 없음.
6. 이미 열린 구대화가 아니라 v0.4.1 release 이후 새 ChatGPT 대화에서 실행.
