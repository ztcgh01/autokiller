# RP 출력 형식 계약

## 말풍선

- 기본 RP 말풍선은 `@인물:`로 시작한다.
- 원문의 태그가 있으면 같은 인물 태그를 유지한다.
- 사용자가 태그 제거를 명시하지 않은 한 최종 RP 결과의 첫 내용은 `@`로 시작한다.
- 서로 다른 인물의 발화를 한 말풍선에 섞지 않는다.
- 같은 인물의 지문과 대사는 해당 인물 말풍선 안에서 유지한다.

## 별표 지문

행동·표정·시선·몸짓·침묵·감각·심리 묘사·배경·주변 반응·내레이터 흡수분 등 **대사가 아닌 모든 서술**은 실제 문자 기준 `\*지문\*` 형식으로 출력한다.

- 시작과 끝 모두 `\*`를 사용한다.
- `*지문\*`, `\*지문*`처럼 반쪽만 이스케이프된 형식을 만들지 않는다.
- 홀수 별표, 열린 채 닫히지 않은 지문을 만들지 않는다.
- 대사가 사이에 끼어 있으면 앞뒤 지문을 억지로 하나의 지문으로 합치지 않는다.
- 새 장면/이어쓰기에서도 별표 없는 평문 서술을 만들지 않는다.
- 굵게 표시나 다른 마크다운을 지문 대신 사용하지 않는다.
- AUTO_KILLER가 ZETA에 적용할 때 이스케이프를 정리하므로 플러그인은 `\*...\*` 계약을 그대로 지킨다.

## 기본 줄바꿈과 한 줄 호흡

사용자가 엔터/문단 분리를 요청하지 않았다면 같은 화자의 한 말풍선 안에서 지문과 대사를 불필요하게 여러 줄로 쪼개지 않는다.

- 기본은 `\*지문.\* 대사.`처럼 한 말풍선 한 줄의 호흡으로 정리한다.
- **대사만 떼고 지문끼리는 떼지 않는다.**
- 지문 내부의 행동들을 이유 없이 여러 줄로 분해하지 않는다.
- `엔터`, `대사 떼줘`, `지문과 대사 따로`, `대사 엔터` 요청이 있을 때만 지문과 대사를 분리한다.
- 분리 요청 시 지문과 대사 사이에 빈 줄 하나를 둔다.

## 속마음

원문에서 속마음으로 쓰인 `(대사)`, `'대사'`, `('대사')` 같은 형식은 속마음으로 유지한다.

- 삭제·흡수·요약하여 일반 지문으로 바꾸지 않는다.
- 실제 발화 대사로 바꾸지 않는다.
- 원문에 없던 `('...')` 속마음을 새로 만들지 않는다.

## 내레이터 `@:`

- `@:` 내레이터는 원칙적으로 최종 결과에 별도 말풍선으로 남기지 않는다.
- 가장 가까운 관련 인물의 `\*...\*` 지문에 자연스럽게 흡수한다.
- 인물에게 귀속할 수 없는 최소한의 장면 전환 정보는 의미 보존을 우선한다.
- 사용자의 서술을 임의로 `@유저:` 또는 사용자 대사로 바꾸지 않는다.
