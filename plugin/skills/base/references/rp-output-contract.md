# RP 출력 형식 계약

## Writing Block

수정, 정리, 합치기, 나누기, 짧출, 새 장면 생성, 이어쓰기 등 모든 RP 관련 결과물은 기본적으로 ChatGPT의 네이티브 Writing Block UI 안에 출력한다.

기존 역병킬러가 사용하던 표준 표현은 다음과 같다.

`:::writing{variant="standard" id="12345"}`

- `12345`는 매 응답마다 임의의 5자리 ID에 해당한다.
- Writing Block의 여는 부분과 닫는 `:::`는 블록 구조를 깨지 않게 유지한다.
- Writing Block 문법을 일반 코드블록이나 평문으로 흉내 내서 출력하지 않는다.
- 플랫폼이 네이티브 Writing Block을 직접 렌더링할 수 있으면 네이티브 UI를 사용한다.

사용자가 명시적으로 다른 출력 형식을 요청한 경우에만 그 요청을 따른다.

## 말풍선 태그

- 최종 출력의 일반 RP 말풍선은 `@인물:` 태그로 시작한다.
- 원문에 `@인물:` 태그가 있으면 같은 인물 태그를 유지한다.
- 사용자가 태그 제거를 요청하지 않는 한, 지문만 태그 없이 단독 결과로 내보내지 않는다.
- 한 인물의 지문과 대사는 해당 인물 말풍선 안에 유지한다.
- `@:` 내레이터는 기본적으로 최종 결과에 남기지 않고 가장 가까운 관련 인물의 지문에 자연스럽게 흡수한다. 다만 인물에게 귀속할 수 없는 최소한의 장면 전환 정보는 의미가 훼손되지 않도록 처리한다.
- 사용자의 서술을 임의로 `@유저:` 대사로 바꾸지 않는다.

## 별표 지문

- 대사가 아닌 행동, 표정, 시선, 침묵, 감각, 심리 묘사, 주변 반응, 배경 묘사는 지문이다.
- 최종 RP 결과의 지문은 실제 문자 기준 `\*지문\*` 형식으로 출력한다. 즉 별표 앞의 역슬래시도 결과에 포함한다.
- 출력 직전에 지문 시작과 끝의 역슬래시+별표 쌍이 빠지지 않았는지 확인한다.
- 인물이 실제로 입 밖에 내는 말만 지문 밖의 대사로 둔다.
- 새 장면 생성/이어쓰기에서도 별표 없는 평문 서술을 만들지 않는다.

AUTO_KILLER는 ZETA에 적용하기 전에 이 이스케이프를 정리하므로, 플러그인은 기존 역병킬러의 출력 계약을 그대로 지킨다.

## 기본 줄바꿈

기본은 지문과 대사를 같은 말풍선 흐름 안에서 붙여 쓰는 형식이다. 사용자가 `엔터`, `대사 떼줘`, `지문 대사 따로`, `대사 엔터`처럼 분리를 요청한 경우에만 지문과 대사 사이를 분리한다.

분리 요청 시 지문과 대사 사이에 빈 줄 하나를 둔다.

## 구조 보존

원문의 다음 구조는 의미가 있는 한 유지한다.

- InfoBox/메시지 박스
- `>` 인용 형식
- 괄호, 따옴표, 말줄임표
- `~`, `!`, `!?`, `…` 같은 캐릭터 고유 기호
- 장면 구분에 필요한 최소 구조

사용자가 구조 변경을 요청하지 않았는데 임의로 코드블록, 목록, 제목, 분석 섹션으로 바꾸지 않는다.
