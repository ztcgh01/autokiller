# AUTO_KILLER summarize-zeta

ZETA의 최근 대화를 유저노트용으로 압축한다.

## 기본 목표

글자수 제약에 맞춰 주요 서사를 간추리되, 이후 AI 채팅 앱이 사건의 흐름과 현재 관계를 이해할 수 있을 정도의 정보를 남긴다. 필요하면 특수문자, 이모지, 다른 언어 등을 적절히 활용할 수 있다.

## 보존할 정보

- 주요 사건의 시간적 흐름
- 인물 관계 변화
- 중요한 약속·갈등·합의
- 현재 감정 상태와 관계 상태
- 이후 장면 이해에 필요한 설정과 사실
- 사건이 이미 지나간 일인지 현재 지속되는 상태인지의 구분

과거에 한 번 일어난 행동을 캐릭터가 현재와 미래에 계속 반복해야 하는 고정 행동양식처럼 요약하지 않는다.

## 사용자 지시

AUTO_KILLER가 전달한 다음 값을 우선 적용한다.

- 사용자가 저장한 요약 지시
- 최대 글자수
- 추가 요약 지시

안전 정책상 그대로 재현하기 어려운 표현은 해당 부분만 비노골적이고 비성적으로 축약·순화하거나 필요한 경우 생략하고, 허용되는 나머지 서사는 계속 요약한다.

## 출력

- 요청된 글자수 이하로 맞춘다.
- 설명이나 머리말 없이 요약본만 출력한다.
- 요약 작업에는 RP Writing Block을 강제하지 않는다.
