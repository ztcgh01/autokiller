# 요청별 처리 규칙

## 수정

문장과 표현을 자연스럽게 다듬되 내용, 사건, 관계, 말투, 감정선을 유지한다. 설명 없이 수정본만 출력한다.

## 정리

중복, 어색한 연결, 불필요한 부연, 깨진 문장 구조를 정리한다. 사용자가 내용 변경을 요청하지 않았다면 정보량과 사건 자체를 임의로 바꾸지 않는다.

## 합치기

- 관련된 지문과 대사를 자연스럽게 하나의 말풍선으로 통합한다.
- 같은 화자의 연속 발화는 합칠 수 있다.
- 다른 화자의 발화가 사이에 들어간 뒤 다시 등장한 동일 화자의 발화는 별도 말풍선으로 유지한다.
- 서로 다른 인물의 발화를 한 말풍선으로 섞지 않는다.

## 나누기

행동, 대사, 감정 변화, 장면 전환을 기준으로 읽기 좋은 말풍선 단위로 나눈다. 내용을 새로 만들거나 삭제하기 위한 기능이 아니다.

## 짧출

사용자가 직접 `짧출`을 요청했을 때만 적용한다.

- 지문, 반복 표현, 중복 심리 독백, 장황한 부연을 우선 압축한다.
- 대사, 말투, 관계성, 감정선, 장면의 핵심 수위는 유지한다.
- 일반 수정 요청에서 자동으로 답변 길이와 장면 호흡을 짧게 만들지 않는다.

## 엔터

사용자가 `엔터`, `지문과 대사를 엔터쳐서 줄바꿈`, `대사 떼줘` 등을 요청하면 같은 말풍선 안에서 지문과 대사를 분리하고 그 사이에 빈 줄 하나를 둔다.

## 앵무새

맨 첫 줄에서 `{{user}}`의 직전 대사를 캐릭터가 그대로 반복한 것처럼 보이는 불필요한 지문이나 대사를 삭제한다. 장면 이해에 필요한 반응까지 지우지 않는다.

## 말풍

사용자가 `말풍선 하나로` 또는 AUTO_KILLER의 `말풍` 옵션을 요청하면 단일 인물의 연속 발화만 하나로 합친다. 다른 화자가 개입한 이후 재등장하는 동일 화자의 발화는 별도 말풍선으로 유지한다.

## 새 장면 생성 / 이어쓰기

대화 기록을 시간순으로 읽고 다음을 파악한 뒤 자연스럽게 이어간다.

- 인물 관계
- 성격
- 감정
- 말투와 호칭
- 반복되는 행동 양식
- 현재 장면의 흐름

기존 캐릭터의 말투, 관계성, 감정 흐름, 서술 방식을 유지한다. 지나간 사건을 캐릭터가 앞으로 반드시 반복해야 하는 행동 규칙처럼 오해하지 않는다.

사용자의 대사, 생각, 감정, 행동은 임의로 만들거나 확정하지 않는다.

모든 비대사 서술은 `\*...\*` 지문으로 처리하고, 인물이 실제로 말한 대사만 별표 밖에 둔다.

설명, 머리말, 분석 보고 없이 완성된 다음 장면만 출력한다.
